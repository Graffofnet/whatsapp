# 🎙️ VoiceChat  

Прототип голосового мессенджера в стиле WhatsApp. Обмен голосовыми 
сообщениями с реальной записью через микрофон, встроенный плеер с 
волновой формой, фиксация записи удержанием (5 сек), удаление долгим 
тапом. Бутерброд-меню с ID пользователя, личными комнатами и 
пригласительными ссылками. 7 стандартных фонов WhatsApp, тёмная тема, 
адаптив под мобильные.

Прототип голосового мессенджера в стиле WhatsApp. Обмен голосовыми сообщениями с реальной записью через микрофон (MediaRecorder API), встроенный плеер с волновой формой, фиксация записи долгим удержанием (5 сек), удаление сообщений долгим тапом. Бутерброд-меню: карточка пользователя с ID из кеша, создание личных комнат, пригласительные ссылки, 7 стандартных фонов WhatsApp. Тёмная тема, адаптив под мобильные.
